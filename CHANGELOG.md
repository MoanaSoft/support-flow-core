# Changelog

## v0.3.0

- Require moanasoft/foundation ^0.4 and align route configuration with Moanasoft global public/admin route conventions.

- Initial SupportFlow Core package.
- Multi-instance Blade widget.
- Configured intents and workflows.
- Fallback contact request storage.
- Basic event tracking.
- Classic and AdminLTE admin views.
